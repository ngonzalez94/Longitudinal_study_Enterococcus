WGS analysis pipeline for E. coli, E. faecalis and E. faecium isolates

Step-by-step Slurm scripts for the NeSI HPC cluster

Overview

This document describes the whole-genome sequencing (WGS) workflow used to characterise Escherichia coli, Enterococcus faecalis and Enterococcus faecium isolates from dairy calves. All steps were run as Slurm jobs on the NeSI HPC cluster.

1. Nullarbor: assembly, QC and core SNP alignment

Nullarbor trims reads, assembles genomes, annotates them, screens for contamination (Centrifuge) and builds a core SNP alignment against a reference.

ecoli_list.txt is a tab-separated file with one isolate per line: isolate_ID <tab> R1.fastq.gz <tab> R2.fastq.gz.

#!/bin/bash -e
#SBATCH --account massey04106
#SBATCH --job-name=nullarbor
#SBATCH --time=48:10:10
#SBATCH --cpus-per-task=24
#SBATCH --mem=100GB
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
NAME="ecoli_long"                       # run name
REF="GCF_000401755v1_genomic.fna"       # reference genome (see species table)
INPUT="ecoli_list.txt"                  # tab-separated: ID, R1, R2
OUTDIR="nullarbor_ecoli_long"           # output folder (must not already exist)
# ----------------------------------------------------------------------

module purge
module load nullarbor/2.0.20191013

nullarbor.pl --name "$NAME" --trim --ref "$REF" \
    --taxoner centrifuge --input "$INPUT" --outdir "$OUTDIR"

nice make all -j 4 -l 54 -C "$OUTDIR" 2>&1 | tee -a "$OUTDIR/nullarbor.log"

Assemblies (contigs.fa) and annotations (.gff, .gbff) from this step are the inputs for most of the steps below. Copy or symlink them into one folder per species, named by isolate (e.g. isolate1.fa, isolate1.gff).

2. ABRicate (PlasmidFinder)

ABRicate v1.0.0 was used with the PlasmidFinder database. Run it in the folder containing the assemblies.

#!/bin/bash -e
#SBATCH --account massey04106
#SBATCH --job-name=plasmidfinder
#SBATCH --time=00:30:00
#SBATCH --mem=2GB
#SBATCH --cpus-per-task=4
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

module purge
module load ABRicate/1.0.0-GCC-11.3.0-Perl-5.34.1

abricate --db plasmidfinder *.fa > plasmidfinder_results.tab
abricate --summary plasmidfinder_results.tab > plasmidfinder_summary.tab

3. RFPlasmid

RFPlasmid predicts whether each contig is chromosomal or plasmid-derived. Set --species to Enterobacteriaceae for E. coli and Enterococcus for the enterococci.

#!/bin/bash

#SBATCH --job-name=RFPlasmid
#SBATCH --time=5:00:00
#SBATCH --mem=36GB
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
SPECIES="Enterococcus"      # Enterobacteriaceae (E. coli) or Enterococcus
# ----------------------------------------------------------------------

module purge
module load RFPlasmid/0.0.18-gimkl-2022a-Python-3.10.5

rfplasmid.py --species "$SPECIES" --jelly --out output --input ./

4. AMRFinderPlus

This loop runs AMRFinderPlus on every isolate listed in list.txt (one isolate name per line, without the .fa extension). Change ORGANISM for the other species.

#!/bin/bash
#SBATCH --account=massey04106
#SBATCH --job-name=amrfinder
#SBATCH --time=5:00:00
#SBATCH --mem=4GB
#SBATCH --cpus-per-task=4
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
ORGANISM="Enterococcus_faecalis"   # Enterococcus_faecalis, Enterococcus_faecium or Escherichia
LIST="list.txt"                    # one isolate name per line (no extension)
# ----------------------------------------------------------------------

module purge
module load AMRFinderPlus/4.2.7-foss-2023a

while read -r sample; do
    amrfinder --organism "$ORGANISM" \
              --output "${sample}_amrfinder.tsv" \
              --nucleotide "${sample}.fa"
done < "$LIST"

5. VirulenceFinder

VirulenceFinder is run from a Python virtual environment, with its database path exported as CGE_VIRULENCEFINDER_DB. The -x flag produces extended output.

#!/bin/bash -e
#SBATCH --account       massey04106
#SBATCH --job-name      virfinder
#SBATCH --time          00:10:00
#SBATCH --mem           2GB
#SBATCH --cpus-per-task 4
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
VF_ENV="/nesi/nobackup/massey04106/bin/virulencefinder_env"
# ----------------------------------------------------------------------

module purge
module load kma/1.4.5-GCC-11.3.0
module load BLAST/2.16.0-GCC-12.3.0
module load BLASTDB/2026-01

source "${VF_ENV}/bin/activate"
export CGE_VIRULENCEFINDER_DB="${VF_ENV}/virulencefinder_db"

for file in *.fa; do
    basename=${file%.fa}
    outdir="vf_${basename}"
    mkdir -p "${outdir}"
    python -m virulencefinder -ifa "${file}" -o "${outdir}" -x
done

6. PointFinder

PointFinder is also run from its own virtual environment. Set SPECIES to escherichia_coli, enterococcus_faecalis or enterococcus_faecium.

#!/bin/bash -e
#SBATCH --account       massey04106
#SBATCH --job-name      pointfinder
#SBATCH --time          01:10:00
#SBATCH --mem           2GB
#SBATCH --cpus-per-task 4
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
SPECIES="escherichia_coli"    # escherichia_coli, enterococcus_faecalis, enterococcus_faecium
PF_ENV="/nesi/nobackup/massey04106/bin/pointfinder_env"
BLASTN="/opt/nesi/CS400_centos7_bdw/BLAST/2.16.0-GCC-12.3.0/bin/blastn"
# ----------------------------------------------------------------------

module purge
module load BLAST/2.16.0-GCC-12.3.0
module load BLASTDB/2024-10

source "${PF_ENV}/bin/activate"

for file in *.fa; do
    basename=${file%.fa}
    outdir="pf_${basename}"
    mkdir -p "${outdir}"

    "${PF_ENV}/pointfinder/PointFinder.py" \
        -i "${file}" \
        -o "${outdir}" \
        -p "${PF_ENV}/pointfinder_db/" \
        -s "${SPECIES}" \
        -m blastn \
        -m_p "${BLASTN}"
done

7. Roary (pangenome)

Roary takes the Prokka/Bakta-style .gff files (as produced by Nullarbor) and builds the pangenome at 95 % protein identity. Options: -e core gene alignment, -n fast alignment with MAFFT, -r R plots, -i 95 minimum identity.

#!/bin/bash
#SBATCH --job-name=roary
#SBATCH --account=massey04106
#SBATCH --time=04:00:00
#SBATCH --cpus-per-task=16
#SBATCH --mem=32G
#SBATCH --output=roary_%j.out
#SBATCH --error=roary_%j.err

module purge
module load Roary/3.13.0-gimkl-2020a

roary -f roary -e -n -r -i 95 -p "$SLURM_CPUS_PER_TASK" *.gff

8. chewBBACA

A cgMLST allele profile was generated with chewBBACA v3.1.2 in three jobs: (A) create the schema, (B) call alleles, (C) extract the cgMLST at a 95 % threshold. Run each species in its own folder, using the matching prodigal training file (.trn).

The three scripts share the same editable variables. Set them in each script.

8A. Create the schema

#!/bin/bash -e
#SBATCH --account       massey04106
#SBATCH --job-name      chewbbaca_schema
#SBATCH --time          01:10:00
#SBATCH --mem           3GB
#SBATCH --cpus-per-task 8
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
CONTIGS="/path/to/species/contigs"   # folder with the assemblies (.fa)
PTF="Ecoli.trn"                      # prodigal training file for the species
# ----------------------------------------------------------------------

module purge
module load chewBBACA/3.1.2-gimkl-2022a-Python-3.11.3

cd "$CONTIGS"

chewBBACA.py CreateSchema -i "$CONTIGS" -o schema_directory \
    --bsr 0.8 --ptf "$PTF" --cpu 16

8B. Allele calling

#!/bin/bash -e
#SBATCH --account       massey04106
#SBATCH --job-name      chewbbaca_allele
#SBATCH --time          12:12:00
#SBATCH --mem           20GB
#SBATCH --cpus-per-task 8
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
CONTIGS="/path/to/species/contigs"
PTF="Ecoli.trn"
# ----------------------------------------------------------------------

module purge
module load chewBBACA/3.1.2-gimkl-2022a-Python-3.11.3

cd "$CONTIGS"

chewBBACA.py AlleleCall -i "$CONTIGS" \
    -g schema_directory/schema_seed \
    -o wgMLST_output --cpu 16 --ptf "$PTF"

8C. Extract the cgMLST (95 % threshold)

#!/bin/bash -e
#SBATCH --account       massey04106
#SBATCH --job-name      chewbbaca_cgMLST
#SBATCH --time          00:10:00
#SBATCH --mem           1GB
#SBATCH --cpus-per-task 6
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

    --genes2remove wgMLST_output/paralogous_counts.tsv

10. Gubbins (remove recombination)

Recombination is removed from the cleaned alignment with Gubbins v3.4, run from a container. -f 30 sets the minimum window size for the filter.

#!/bin/bash -e
#SBATCH --account massey04106
#SBATCH --job-name=gubbins
#SBATCH --time=00:10:00
#SBATCH --cpus-per-task=4
#SBATCH --mem=2GB
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
GUBBINS_IMG="/path/to/gubbins-3.4.aimg"   # Gubbins apptainer image
ALIGNMENT="clean.full.aln"                # output of step 9
# ----------------------------------------------------------------------

module purge

export GUBBINS_CMD="apptainer exec --env LC_ALL=C.utf8,LANG=C.utf8 ${GUBBINS_IMG}"

$GUBBINS_CMD run_gubbins.py -f 30 -p gubbins "$ALIGNMENT"

The recombination-free tree is gubbins.final_tree.tre.

11. Extract protein sequences for a gene from GenBank (.gbff) files

This script finds a gene by its annotated name (e.g. gltP) in each .gbff file and writes its protein translation to <isolate>_<gene>.faa. Isolates without a match are reported and no empty file is kept. Run it in the folder containing the .gbff files.

Note

The script uses match() with an array argument, which requires GNU awk (gawk).

#!/bin/bash
#SBATCH --account=massey04106
#SBATCH --job-name=extraction
#SBATCH --time=01:00:00
#SBATCH --mem=4GB
#SBATCH --error         %x_%j.err
#SBATCH --output        %x_%j.out

# ---- Editable variables ----------------------------------------------
gene_query="gltP"        # gene name exactly as annotated in the gbff
# ----------------------------------------------------------------------

for gbff_file in *.gbff; do

    isolate="${gbff_file%.gbff}"
    outfile="${isolate}_${gene_query}.faa"

    awk -v gene="$gene_query" -v isolate="$isolate" '
        /\/gene="/ {
            match($0, /\/gene="([^"]+)"/, arr)
            current_gene = arr[1]
        }
        /\/locus_tag="/ {
            match($0, /\/locus_tag="([^"]+)"/, arr)
            locus = arr[1]
        }
        /\/translation="/ {
            in_translation = 1
            match($0, /\/translation="([^"]+)/, arr)
            translation = arr[1]
        }
        in_translation && !/\/translation="/ {
            if (/\"/) {
                gsub(/"/, "")
                translation = translation $0
                in_translation = 0
                if (current_gene == gene) {
                    gsub(/ /, "", translation)
                    print ">" isolate "|" locus "|" current_gene
                    print translation
                }
                translation = ""
            } else {
                gsub(/ /, "", $0)
                translation = translation $0
            }
        }
    ' "$gbff_file" >> "$outfile"

    if [ -s "$outfile" ]; then
        echo "Found match in ${isolate} → ${outfile}"
    else
        rm -f "$outfile"
        echo "No match in ${isolate}"
    fi

done
